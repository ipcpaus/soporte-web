# Soporte Web — App Delihealths

Página web de guía y soporte para usuarios de la App Delihealths. Proporciona instrucciones paso a paso para descargar la aplicación, iniciar sesión, identificar el ID de paciente, validar el acceso mediante SMS y resolver dudas frecuentes durante el proceso de ingreso.
